| Version | Supported          |

## Reporting a Vulnerability

The SentinelAI team takes platform security and target authorization boundaries with the highest level of priority.

If you discover a security vulnerability within SentinelAI (e.g., SSRF bypass, secret leak, RBAC bypass, prompt injection escalation), please do **NOT** open a public issue.

Instead, please report it via responsible disclosure:
- Email: **security@sentinelai.io** or through private GitHub Security Advisories.
- Include detailed steps to reproduce the vulnerability, including scan target parameters or HTTP request payloads.
- We will acknowledge receipt within 24 hours and provide a remediation timeline.

Thank you for helping keep SentinelAI and our users secure.
